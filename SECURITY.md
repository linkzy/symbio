# Security policy

Symbio runs AI agents that execute commands on your machine, so security reports are taken
seriously. How Symbio protects you, and the limits of that, is described in
[docs/security.md](docs/security.md).

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Report them privately through GitHub's
**Security → Report a vulnerability** form on this repository.

Include what an attacker could do, the steps to reproduce, and the affected version or commit.
You'll get an acknowledgment as soon as possible, and credit in the fix's notes if you'd like.

## Supported versions

Symbio is pre-1.0; only the latest version on `main` receives fixes.
